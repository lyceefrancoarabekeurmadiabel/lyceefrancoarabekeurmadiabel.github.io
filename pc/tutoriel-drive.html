Comment ajouter un cours ou un TD ?

Guide pas à pas — Google Drive / OneDrive. Pour économiser le stockage du lycée, tous les cours sont hébergés sur votre espace personnel.

💡 Pourquoi cette méthode ?
Les fichiers stockés directement sur le serveur du site consomment un quota limité. En les hébergeant sur votre Google Drive (15 Go gratuits) ou OneDrive (5 Go gratuits), vous bénéficiez d'un espace quasi illimité, et les élèves y accèdent en un clic.
1

📤 Uploadez votre fichier sur Google Drive ou OneDrive

Ouvrez drive.google.com (ou onedrive.live.com) sur votre ordinateur ou téléphone, puis :

  • Créez un dossier LFAKM — Mes cours
  • Glissez-déposez votre fichier (PDF, Word, PowerPoint…)
  • Rangez par matière et par classe pour vous y retrouver
💡 Astuce : vous n'avez pas besoin de renommer le fichier. Le titre que vous donnerez sur le site LFAKM sera celui affiché aux élèves.
2

🔓 Partagez le fichier en « Toute personne avec le lien »

Clic droit sur le fichier → Partager → dans le menu déroulant, choisissez « Toute personne disposant du lien » → cliquez sur Copier le lien.

👥 Partager avec : Toute personne disposant du lien ▼ Lecture
⚠️ Important : si vous laissez sur « Accès restreint », les élèves verront un message « Accès refusé ». Vérifiez bien ce réglage avant de copier le lien.
3

📋 Copiez le lien du fichier

Après le partage, le lien ressemble à ceci :

https://drive.google.com/file/d/1AbC...xYz/view?usp=sharing

Vous pouvez aussi copier directement l'adresse depuis la barre du navigateur quand le fichier est ouvert.

4

📎 Ajoutez le lien sur le site LFAKM

Rendez-vous sur la page Ressources, ouvrez la classe et la matière concernées, puis cliquez sur le bouton :

📎 Ajouter un cours (Google Drive / OneDrive)
  • Donnez un titre clair (ex : « Chapitre 3 — Les alcools »)
  • Collez le lien copié à l'étape 3 (Ctrl+V)
  • Cliquez sur OK
✅ Le cours apparaît immédiatement dans la section « Cours » de la matière. Les élèves peuvent l'ouvrir ou le télécharger directement.
🎉 C'est terminé !
Vous pouvez répéter ces 4 étapes pour chaque cours ou TD. Aucune limite de quantité, aucune consommation du stockage du lycée.
💡 Astuces bonus (cliquez pour voir)
  • Modifier un cours : mettez simplement à jour le fichier dans votre Drive. Le lien reste le même, le contenu est mis à jour automatiquement pour les élèves.
  • Supprimer un cours : supprimez le fichier de votre Drive, puis retirez le lien depuis le site (bouton ✕ à côté du cours).
  • Plusieurs fichiers pour une même leçon : créez un dossier Drive, partagez-le en « Toute personne avec le lien », et collez le lien du dossier.
  • Vidéos : utilisez plutôt le bouton 🎥 Lien vidéo YouTube — c'est plus léger et plus rapide à charger.
  • Quota Drive gratuit : 15 Go par compte Google, soit largement de quoi stocker toutes vos matières pendant plusieurs années.
  • OneDrive : 5 Go gratuits, mais si votre lycée a un abonnement Microsoft 365, vous avez probablement 1 To.
