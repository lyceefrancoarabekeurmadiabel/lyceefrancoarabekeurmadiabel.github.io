🎬 Choisis un régime de fonctionnement

Dans un circuit RLC, la résistance R joue un rôle déterminant. Selon sa valeur, le circuit oscille de manière très différente. Il existe une valeur critique R_c = 2√(L/C) qui sépare les comportements.

👇 Choisis un régime ci-dessous (tu pourras changer à tout moment à l'étape 4).
1️⃣ Pseudo-périodique R = 50 Ω
R < R_c : le circuit oscille mais l'amplitude diminue progressivement à cause des pertes dans R.
🎯 Analogie : balançoire avec frottements → balancements qui s'atténuent.
2️⃣ Critique R = 632 Ω
R = R_c : le circuit revient à 0 le plus rapidement possible sans jamais osciller. C'est le cas limite entre les deux autres.
🎯 Analogie : porte qui se ferme sans claquer — vitesse optimale.
3️⃣ Apériodique R = 1500 Ω
R > R_c : le circuit revient à 0 lentement, sans osciller. La résistance est trop forte pour permettre les oscillations.
🎯 Analogie : porte lourde qui se ferme lentement, freinée par les frottements.
4️⃣ Personnalisé R = à choisir
Explore librement l'influence de R entre 10 Ω et 5000 Ω.
🎯 Utilise cette option pour trouver toi-même la valeur critique R_c.
Ω
📐 Valeur critique : Avec L = 1 H et C = 10 µF, la résistance critique vaut R_c = 2√(L/C) = 2√(10⁵) ≈ 632 Ω.
📚 Notions à connaître
  • Un circuit RLC dissipe son énergie dans la résistance R (effet Joule).
  • Loi des mailles : U_C + U_R + U_L = 0
  • Résistance critique : R_c = 2√(L/C)
  • Pseudo-période (régime 1) : T ≈ T₀ = 2π√(LC)
  • Facteur de qualité : Q = (1/R)·√(L/C) (mesure l'acuité de la résonance)
  • Plus R est petite, plus les oscillations durent longtemps (amortissement faible).
  • Plus R est grande, plus l'amortissement est rapide (régimes critique puis apériodique).

🎬 Choisis le mode de mesure

L'oscilloscope peut mesurer la tension aux bornes d'un composant, ou simultanément les tensions de deux composants différents.
1️⃣ Mesurer U_C (condensateur)
Voie 1 (+) → borne + de C  |  Voie 2 (−) → borne − de C
2️⃣ Mesurer U_R (résistor)
Voie 1 (+) → borne gauche de R  |  Voie 2 (−) → borne droite de R
3️⃣ Mesurer deux composants simultanément
Voie 1 (+) → borne + de C (mesure U_C)  |  Voie 2 (−) → borne de R (mesure U_R)
Permet de comparer U_C et U_R en même temps.

🔵 Oscillations libres amorties

Observe la décroissance des tensions et du courant pour le régime choisi.

🔵 U_C(t) — tension du condensateur

U_C(t) = U₀ · e^(−t/τ) · cos(ω·t)
Amortissement lent : oscillations nombreuses

🟠 U_R(t) — tension du résistor

U_R(t) = − R · C · dU_C/dt
Image du courant i(t) = U_R / R

⚡ i(t) — courant dans le circuit

i(t) = − C · dU_C/dt  =  U_R(t) / R
💡 À retenir :
• Le régime pseudo-périodique produit des oscillations dont l'amplitude décroît exponentiellement.
• Le régime critique est le retour à 0 le plus rapide sans dépassement.
• Le régime apériodique retourne à 0 lentement, sans oscillation.
• Dans tous les cas, l'énergie est dissipée dans R (effet Joule).
• U_R(t) est proportionnelle au courant : U_R = R·i. On en déduit i(t).

🎯 Les trois régimes du RLC libre

Compare les trois comportements sur une même courbe.

Pseudo-périodique
R < 632 Ω · oscillations
Critique
R = 632 Ω · retour rapide
Apériodique
R > 632 Ω · retour lent
💡 Critère de séparation : La valeur critique R_c = 2√(L/C) sépare les deux grands types de comportement. Dans ce TP, avec L = 1 H et C = 10 µF, on a R_c ≈ 632 Ω.

⚡ Dissipation de l'énergie

L'énergie totale du circuit décroît : elle est dissipée en chaleur dans R.

💡 À retenir :
• E_C = ½ · C · U_C² : énergie du condensateur
• E_L = ½ · L · i² : énergie de la bobine
• E_totale = E_C + E_L : décroît à cause de la résistance
• La puissance dissipée dans R vaut P = R · i² (effet Joule).

🌍 Applications dans la vie courante

Le circuit RLC est présent partout en électronique et au-delà.

📻
Récepteur radio (sélectivité)
Le facteur Q détermine la finesse
En agissant sur R, on contrôle la finesse de l'accord. Un Q élevé (R faible) sépare mieux les stations proches en fréquence.
🔔
Sonnerie / Carillon
Oscillations amorties = son pur
Un circuit RLC excité produit un son amorti à la fréquence de résonance f₀. C'est le principe des sonneries, cloches et carillons électroniques.
⚡
Circuit d'allumage
Oscillations amorties contrôlées
Dans les systèmes d'allumage (bougies, flash), la décharge oscillante d'un circuit RLC produit une impulsion brève et intense. La résistance ajuste la durée de l'impulsion.
🏥
Défibrillateur
Impulsion contrôlée
Le défibrillateur cardiaque utilise un circuit RLC pour générer une impulsion électrique amortie calibrée, qui restaure le rythme du cœur.

🧮 Exercices guidés

Applique ce que tu as appris avec 3 exercices progressifs.

1
Calculer la résistance critique R_c
Un circuit RLC utilise une bobine L = 2 H et un condensateur C = 50 µF. Quelle est la résistance critique R_c ?
  • Formule : R_c = 2·√(L/C)
  • L/C = 2 / 50×10⁻⁶ = 2 / 0,00005 = 40 000
  • √(L/C) = √40000 = 200
  • R_c = 2 × 200 = 400 Ω
2
Identifier le régime
Avec le même circuit (L = 2 H, C = 50 µF, R_c = 400 Ω), quel régime observe-t-on si R = 250 Ω ?
  • Comparer R à R_c : ici R < R_c
  • R petit → oscillations amorties
  • Régime : pseudo-périodique
3
Pseudo-période T
Pour le régime pseudo-périodique avec L = 1 H et C = 10 µF, quelle est la pseudo-période T (approximativement égale à T₀) ?
  • Formule : T ≈ T₀ = 2π√(L·C)
  • L·C = 1 × 10×10⁻⁶ = 10⁻⁵ s²
  • √(L·C) ≈ 3,16×10⁻³ s = 3,16 ms
  • T = 2π × 3,16 ms ≈ 19,9 ms
